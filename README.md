# GOMOKU 在线五子棋

一个简洁、可与朋友实时联机的五子棋网页。创建房间后分享链接，另一位玩家打开即可开始。

## 功能

- 15 × 15（标准）、19 × 19（大型）、21 × 21（超大型）、25 × 25（巨型）
- 每位玩家可在自己的页面将棋盘缩放至 60%–200%，放大后可拖动查看
- 第一次点击显示落子预览，再次点击同一位置才确认，防止误触
- 支持鼠标或单指直接拖动棋盘，移动端支持双指缩放和移动
- 房主可选择每方 5、10、15 分钟或不限时
- 三三、四四、长连三种黑棋禁手可分别开启或关闭
- 服务器端胜负与禁手判断
- 六位房间号和一键复制邀请链接
- 黑白双方实时同步、断线与重连提示
- 房间设置会实时展示给双方
- 双方确认后再来一局
- 电脑、平板和手机自适应界面

## 本地运行

需要安装 Node.js 18 或更高版本。

```bash
npm install
npm start
```

浏览器打开 `http://localhost:3000`。要在一台电脑上测试双方，可分别使用普通窗口和无痕窗口。

## 发布到互联网

本项目可部署在 Render、Railway 或其他支持 Node.js 和 WebSocket 的平台。

- Build Command：`npm install`
- Start Command：`npm start`
- Node.js 版本：18 或更高

服务器会自动读取平台提供的 `PORT` 环境变量。当前房间仅保存在服务器内存中，服务重启后正在进行的房间会消失。
