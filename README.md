# GOMOKU 在线五子棋

一个简洁、可与朋友实时联机的五子棋网页。创建房间后分享链接，另一位玩家打开即可开始。

## 功能

- 15 × 15（标准）、19 × 19（大型）、21 × 21（超大型）、25 × 25（巨型）
- 每位玩家可在自己的页面将棋盘缩放至 60%–200%，放大后可拖动查看
- 第一次点击显示落子预览，再次点击同一位置才确认，防止误触
- 支持鼠标或单指直接拖动棋盘，移动端支持双指缩放和移动
- 房主可选择每方 5、10、15 分钟或不限时
- 三三、四四、长连三种黑棋禁手可分别开启或关闭
- 服务器端按连珠定义识别真三、假三、四和长连，不用容易误判的固定字符串模板
- 三必须能通过合法延伸形成两端均可成五的直四；贴边、受阻，以及延伸会形成长连或四四的假三不计
- 同一组四子只算一个四，即使它有两个成五点；同一直线上的两个不同四仍会分别计数
- 黑棋恰好五连优先于同一手产生的其他禁手；六枚及以上不算恰好五连
- 六位房间号和一键复制邀请链接
- 黑白双方实时同步、断线与重连提示
- 房间设置会实时展示给双方
- 双方确认后再来一局
- 电脑、平板和手机自适应界面
